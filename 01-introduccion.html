Tailwind CSS en DIW Lección 1 de 8

1. Introducción a Tailwind CSS

Tailwind es un framework CSS utility-first: en lugar de darte componentes ya hechos (como .card o .navbar en Bootstrap), te da cientos de clases pequeñas. Cada clase aplica una sola propiedad CSS, y el diseño se construye combinándolas directamente en el HTML.

Si sabes CSS, ya sabes Tailwind: solo tienes que aprender cómo se llama cada propiedad.

CSS tradicional frente a utilidades

Este es un botón hecho con CSS tradicional. Inventas un nombre de clase y escribes sus estilos en otro archivo:

<button class="boton-comprar">Comprar</button>

/* estilos.css */
.boton-comprar {
  background-color: #0284c7;
  color: white;
  padding: 0.5rem 1rem;
  border-radius: 0.375rem;
  font-weight: 600;
}
.boton-comprar:hover {
  background-color: #0369a1;
}

Y este es el mismo botón con Tailwind. No hay archivo CSS: cada clase es una de las propiedades de arriba.

ClaseCSS que genera
bg-sky-600background-color azul cielo, tono 600
text-whitecolor: white
px-4padding-inline: 1rem (izquierda y derecha)
py-2padding-block: 0.5rem (arriba y abajo)
rounded-mdborder-radius: 0.375rem
font-semiboldfont-weight: 600
hover:bg-sky-700Al pasar el ratón, fondo un tono más oscuro

Ventajas e inconvenientes

Ventajas

  • No hay que inventar nombres de clases ni saltar entre el HTML y el CSS.
  • Los cambios son locales: tocar las clases de un elemento no rompe otro elemento de la página.
  • Todo el diseño usa la misma escala de espacios, tamaños y colores, así que queda coherente.
  • El CSS final es pequeño: Tailwind solo genera las clases que de verdad usas.

Inconvenientes

  • El HTML se llena de clases y al principio cuesta leerlo.
  • Si repites el mismo elemento muchas veces, repites también todas sus clases. En la lección 8 verás cómo evitarlo.
  • No trae componentes con JavaScript (menús, modales, acordeones). Hay que hacerlos a mano o con otra librería.

Cómo enlazar Tailwind por CDN

Para aprender basta con añadir esta línea en el head. Es lo que usan todas las lecciones de este repositorio:

<script src="https://cdn.jsdelivr.net/npm/@tailwindcss/browser@4"></script>

El CDN es para practicar, no para publicar una web. Genera el CSS en el navegador cada vez que se carga la página, y eso es lento. En un proyecto real se instala con Vite (carpeta proyecto-vite), que genera un archivo CSS pequeño una sola vez.

Cómo leer una clase

Casi todas las clases siguen el patrón propiedad-valor, y a veces llevan delante un prefijo con una condición:

ClasePrefijoPropiedadValor
text-lg—tamaño de textogrande
bg-red-500—color de fondorojo, tono 500
mt-4—margin-top4 × 0,25 rem = 1 rem
md:flexmd: (pantallas medianas o más)displayflex
hover:underlinehover: (al pasar el ratón)decoración de textosubrayado

Si no sabes cómo se llama una clase, busca la propiedad CSS en la documentación (atajo Ctrl + K). Y para ver qué CSS genera una clase, selecciona el elemento en las DevTools del navegador.

Instala la extensión Tailwind CSS IntelliSense de VS Code. Autocompleta las clases y muestra el CSS de cada una al pasar el ratón. Funciona cuando el proyecto tiene Tailwind instalado (con Vite), no con el CDN.

Ejercicio: caja de aviso

Crea un archivo HTML nuevo, enlaza Tailwind por CDN y maqueta una caja de aviso como las que avisan de un error en un formulario:

  • Fondo rojo muy claro y borde rojo a la izquierda, de 4 px.
  • Un título en negrita, en rojo oscuro.
  • Un texto debajo, en rojo medio.
  • Espacio interior y esquinas un poco redondeadas.

Pista: la clase para el borde izquierdo de 4 px es border-l-4.
