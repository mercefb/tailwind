Tailwind CSS en DIW Lección 8 de 8

8. Tema propio y reutilización

Hasta ahora has usado los colores y tamaños que trae Tailwind. En un proyecto real querrás los colores y la tipografía de tu marca, y no repetir veinte clases en cada botón. Esta lección resuelve las dos cosas.

Con el CDN, la configuración se escribe en un <style type="text/tailwindcss"> dentro del head. Abre el código fuente de esta página para verla entera. En un proyecto con Vite, lo mismo va en tu archivo CSS, debajo de @import "tailwindcss";.

Tu tema con @theme

Dentro de @theme se declaran variables CSS con un prefijo concreto. Según el prefijo, Tailwind crea las clases correspondientes:

@theme {
  --color-marca-500: #2f7d4f;    /* crea bg-marca-500, text-marca-500, border-marca-500… */
  --color-marca-600: #25643f;
  --font-display: Georgia, serif; /* crea font-display */
  --radius-tarjeta: 1.25rem;      /* crea rounded-tarjeta */
}
Prefijo de la variableClases que crea
--color-*bg-*, text-*, border-*, ring-*, outline-*…
--font-*font-* (familia tipográfica)
--text-*text-* (tamaño de letra)
--radius-*rounded-*
--shadow-*shadow-*
--breakpoint-*Prefijos responsive nuevos, como 3xl:

Los valores de Tailwind siguen disponibles: solo añades los tuyos. Y como son variables CSS, también puedes usarlos en CSS normal: color: var(--color-marca-500).

Ecológico

No repetir clases

Si tienes diez botones iguales, tendrás diez veces la misma lista de clases. Hay tres soluciones, de más a menos recomendada:

  1. Un componente o una plantilla. En React, Vue, Astro o PHP, el botón se escribe una vez como componente y se reutiliza. Es lo que se hace en proyectos reales, y lo verás en otros módulos.
  2. Un bucle. Si los elementos salen de una lista de datos (productos, noticias), el HTML se genera con un bucle y las clases se escriben una sola vez.
  3. @apply, cuando trabajas con HTML estático, como en estas prácticas. Agrupa varias utilidades bajo una clase tuya.

Agrupar utilidades con @apply

Se escribe dentro de @layer components, para que las utilidades sueltas puedan sobrescribirlo. En el ejemplo, el segundo botón usa btn-marca y además w-full, y el tercero cambia el color de fondo con una utilidad.

@layer components {
  .btn-marca {
    @apply inline-block rounded-lg bg-marca-500 px-4 py-2 font-semibold text-white
           hover:bg-marca-600 focus-visible:outline-2 focus-visible:outline-offset-2
           focus-visible:outline-marca-500;
  }
}
Comprar Comprar (ancho completo) Comprar (más oscuro)

No conviertas todo en clases con @apply: acabarías escribiendo CSS tradicional con más pasos. Úsalo para piezas que se repiten mucho, como botones o etiquetas.

Utilidades propias con @utility

Si echas en falta una utilidad, puedes crearla. A diferencia de una clase normal, una utilidad creada con @utility admite todos los prefijos: hover:, md:, dark:…

@utility marco-punteado {
  outline: 2px dashed currentColor;
  outline-offset: 4px;
}

Pasa el ratón: hover:marco-punteado

Ejercicio: tema de marca

Inventa una marca (una librería, un gimnasio, una app…) y:

  1. Define en @theme un color de marca con al menos tres tonos (claro, normal y oscuro) y una fuente para títulos.
  2. Crea con @apply dos clases: btn-principal y btn-secundario (este último solo con borde).
  3. Maqueta un hero con un título en la fuente de marca, un texto y los dos botones.

Comprueba que puedes cambiar el color de toda la página tocando solo el @theme.

Ver solución

Configuración (en el head con el CDN, o en src/style.css con Vite):

@theme {
  --color-tinta-50: #f5f3ff;
  --color-tinta-500: #6d28d9;
  --color-tinta-700: #4c1d95;
  --font-titulo: Georgia, serif;
}

@layer components {
  .btn-principal {
    @apply rounded-lg bg-tinta-500 px-5 py-2.5 font-semibold text-white hover:bg-tinta-700
           focus-visible:outline-2 focus-visible:outline-offset-2 focus-visible:outline-tinta-500;
  }
  .btn-secundario {
    @apply rounded-lg border-2 border-tinta-500 px-5 py-2 font-semibold text-tinta-700 hover:bg-tinta-50
           focus-visible:outline-2 focus-visible:outline-offset-2 focus-visible:outline-tinta-500;
  }
}
