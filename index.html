Tailwind CSS en DIW

Ocho lecciones para aprender Tailwind CSS v4. Cada lección tiene explicación, ejemplos con su código, una tabla de referencia y un ejercicio resuelto.

Estas páginas cargan Tailwind por CDN, así que necesitan conexión a internet. Para el proyecto de clase se usa Vite: mira la carpeta proyecto-vite.

Lección 1 Introducción Utility-first, CDN y cómo leer una clase Lección 2 Espaciado y tamaños Padding, margin, anchos, altos y valores arbitrarios Lección 3 Tipografía, color, bordes y sombras Texto, paleta, opacidad, esquinas y sombras Lección 4 Flexbox Dirección, alineación, gap y reparto de espacio Lección 5 Grid y contenedores Columnas, celdas que ocupan varias columnas y maquetas de página Lección 6 Responsive Mobile first y breakpoints Lección 7 Estados y modo oscuro hover, focus, group, transiciones y dark Lección 8 Tema propio y reutilización @theme, @apply y @utility
